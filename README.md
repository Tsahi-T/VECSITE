# וקטור על — אתר תצוגה למנהלים

אתר סטטי (Front בלבד, ללא אינטרנט) שמציג את עיקרי מסמך
"בינה מבוססת מארג מידע וקישוריות".

## הפעלה

פותחים את `index.html` בדאבל-קליק. זהו. אין צורך בשרת, אינטרנט או התקנה.

## עריכת תוכן

**עורכים רק את `data.js`** — קובץ טקסט פשוט עם הערות בעברית שמסבירות כל חלק.
אין צורך לגעת ב-`index.html`. שומרים, מרעננים את הדפדפן, והשינוי מופיע.

| קבוע ב-data.js | מה הוא שולט |
|---|---|
| `SITE` | כותרות, משפט מטרה ורעיון מרכזי (עמוד הפתיחה) |
| `ARCH` | שקף הארכיטקטורה (שכבות + וקטורים) |
| `PILLARS` | 4 העמודים: מארג מידע, תשתית, וקטור תוכנה, וקטור חיילי — כל אחד עם 8 תתי-פרקים |
| `WORKPLAN` | סדר העבודה הספירלי |
| `KPIS` | מדדי הצלחה |
| `RISKS` | ניהול סיכונים (אדום) |
| `SUMMARY` | שקף הסיכום |

## שימוש

- **ניווט ימני** — קבוצות מתקפלות; לכל וקטור אפשר לפתוח את 8 תתי-הפרקים.
- **מצב מצגת** — כפתור 🎬 בכותרת (או מקש `P`). דפדוף בחצים / רווח, יציאה ב-`Esc`.
- **חיפוש** — שורת חיפוש בכותרת; לחיצה על תוצאה קופצת למקום ומדגישה אותו.
- **מצב בהיר/כהה** — כפתור ☀️/🌙 בכותרת. הבחירה נשמרת לפעם הבאה.
- רקע חלקיקים מקושרים בתנועה עדינה (כבוי אוטומטית אם המערכת מוגדרת לצמצום אנימציות).
- רספונסיבי — עובד גם במסכים צרים (הניווט הופך לתפריט ☰).

## קבצים

- `index.html` — העיצוב והלוגיקה (לא נוגעים בשוטף)
- `data.js` — התוכן (זה מה שעורכים)
- `*OLD*` — גרסת הדוגמה הקודמת, לעיון בלבד
